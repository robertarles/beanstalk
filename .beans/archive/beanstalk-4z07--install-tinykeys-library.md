Add tinykeys to project dependencies for robust keyboard shortcut handling

## Details

Run `npm install tinykeys` to add the library. Tinykeys provides clean handling of key sequences (like 'g g'), modifier keys, and cross-platform keyboard quirks. It's lightweight (~1KB) and designed specifically for keyboard shortcuts. Verify the installation by checking package.json and ensuring the package appears in node_modules.
