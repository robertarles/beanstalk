Execute the npm install command to add tinykeys package to the project dependencies

## Details

Run `npm install tinykeys` in the project root directory. This will download the tinykeys package (~1KB) from npm registry and add it to node_modules. The package provides clean handling of keyboard shortcuts including key sequences (like 'g g'), modifier keys, and cross-platform keyboard quirks.
