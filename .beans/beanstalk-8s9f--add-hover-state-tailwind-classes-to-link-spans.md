Update the className of link spans to include hover state styling for both light and dark modes

## Details

Add the following hover classes to the link span className: hover:text-blue-600 (darker text on hover), hover:bg-blue-50 (light background highlight in light mode), and dark:hover:bg-blue-900/20 (subtle dark mode background). These classes provide visual feedback when users hover over clickable links.
